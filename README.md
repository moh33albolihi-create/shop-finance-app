# نظام محاسبة المحل

تطبيق ويب بسيط (ملف واحد HTML) لإدارة حسابات محل صغير: الإيرادات، المصروفات، السحوبات، الأجهزة (شراء/بيع)، الالتزامات الثابتة، المناديب، والتقفيلة اليومية.

## الاستخدام
افتح الرابط التالي مباشرة من أي متصفح:
https://moh33albolihi-create.github.io/shop-finance-app/

البيانات تُحفظ محليًا في متصفحك فقط (localStorage) ولا يتم رفعها لأي خادم.
